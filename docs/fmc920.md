# FMC920 / dual-SIM (tracker contract)

**Not required for Platform V1.** Do not open TCP :5027 until this SKU is contracted and `server/modules/deployed.ts` lists `truck_tracker`.

## Default unit

**Teltonika FMC920** — 4G Cat 1 + 2G, Codec **8 / 8E**. One SIM. Small, 12V, our ingest is built for this protocol.

Do **not** replace it with a Starlink/RUT router as the only GPS. Starlink is optional **WiFi** for the marshal phone and camp.

## Wiring (installer)

- Permanent 12V (not accessory-only if the truck idles). Fuse the positive.
- GNSS antenna with sky view — not under a steel roof if you can avoid it.
- DIN1 / ignition if the SOW uses ignition as go-live. Confirm with the installer.
- IMEI recorded in the **server allowlist**, never in the SPA.

## Configurator profile (carnival weekend)

- Protocol: Codec **8E** (or 8). Records: **min 1**.
- Send period while moving: start at **10s**. Organizer can widen via FOTA if congestion bites.
- **Sleep off** for the event weekend.
- Home-operator list = the live SIM’s MCC/MNC (Trinidad) so it does not sit in Unknown/roaming rates.
- APN: the carrier’s current APN (confirm with Digicel or bmobile). Data plan that survives parade week.

Device clock: **GMT+0**. Server stores **UTC**. Display `America/Port_of_Spain`.

Persistent **TCP** session to the ingest host (do not reconnect per record).

## Dual-SIM later (same server)

If carnival cell is the pain, upgrade to **FMC125** (confirm **regional SKU** for TT bands). Same Codec 8 ingest. Digicel in SIM1, bmobile in SIM2 (or reverse after a **route test**). Two APNs. Not FMB125 (2G-only). Not FMB640-class.

## Marshal iPhone fallback

If the box dies: signed-in organizer/marshal, HTTPS, Precise Location, page kept on screen, phone charging. Label for patrons: **Updated from a marshal’s phone**. FMC920 wins when it returns.

## Carnival day stack

1. FMC920 on SIM  
2. Cell dies → marshal iPhone (cell or Starlink WiFi)  
3. No sky on the dish → phone on cell, or last-known  

Route-test the SIM on the actual parade path before the weekend.
